# Builder's Code

A lightweight one-page contractor portfolio built with plain HTML and CSS.

## Stack
- HTML
- CSS
- One locally stored generated presentation image
- No JavaScript framework
- No build step

## Before final public launch
Replace the contact note in `index.html` with the contractor's real WhatsApp/phone details and replace the presentation imagery with real completed-job photos when available.

## Deployment
The site is static and ready for GitHub Pages, Netlify, Cloudflare Pages, or any normal web host.
